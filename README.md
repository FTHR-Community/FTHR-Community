## What FTHR stands for

> **Your privacy isn't currency.**

The key idea behind FTHR’s software is rather simple: people need to have
ownership of the tools and remain in control of the data generated by these
tools. It means being local-first if possible, having a transparent development
process, and avoiding any unnecessary cloud dependency or forced subscriptions just
to use the basic feature.

Open-source software is important since users and contributors have to know what
is running on their machines. FTHR wants to create efficient tools without making
users pay every time they want to improve them.

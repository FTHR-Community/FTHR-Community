## What FTHR stands for

> **Your data is yours. Privacy isn't a premium feature.**

FTHR builds useful software around a straightforward idea: people should own
the tools they use and stay in control of the data those tools create. That
means local-first behaviour where practical, transparent development, and no
unnecessary cloud dependency or recurring subscription simply to use a core
feature.

Open-source software matters because users and contributors should be able to
understand what runs on their machines. FTHR aims to make capable tools without
turning every improvement into another monthly payment.

## FTHR Clips

<p>
<img src="https://img.shields.io/badge/STATUS-PRIVATE%20PRE--ALPHA-6C5CE7?style=flat-square" alt="Private pre-alpha" />
<img src="https://img.shields.io/badge/WINDOWS-PRIMARY-171717?style=flat-square" alt="Windows is the primary platform" />
<img src="https://img.shields.io/badge/LINUX-EXPERIMENTAL-555555?style=flat-square" alt="Linux support is experimental" />
<img src="https://img.shields.io/badge/LICENSE-GPL--3.0--ONLY-171717?style=flat-square" alt="GPL-3.0-only" />
</p>

FTHR Clips puts that philosophy into practice for gaming capture. It is a
local-first replay recorder that keeps capture and clip saving on the user's
machine by default, without requiring an account or cloud upload.

The project is currently in private pre-alpha qualification. Windows is the
primary tested platform; Linux support remains experimental. FTHR Clips is
licensed `GPL-3.0-only`, and its current capabilities and limitations are being
verified before a public alpha release.
